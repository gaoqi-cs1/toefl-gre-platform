TOEFL / GRE 刷题平台 · 数据模型 ER 图
依据 toefl_db 的 information_schema.columns 与 key_column_usage 实际结构绘制（2026-11-15）；括号内行数取自 SELECT COUNT(*)。全库 32 张表，按四组数据族分页展示。
★ 物理外键（全库仅 2 处） 绿箭头：主链 1 : N 灰箭头：子表记录回指套题 其余关联为应用层逻辑外键
① 托福分块 tpo_*
tpo 套系 → 篇章（含音频与中文译文）→ 题目（含答案与解析）；作答与错题靠 user_id 逻辑关联。
② 真题套题 full_*
随机组卷时整篇复制进 full_section / full_question；一次模考一条 record，逐题作答写 answer 子表。
③ GRE 分块练习 gre_section / gre_question / gre_answer / gre_wrong
与 tpo_*、full_* 完全隔离；gre_wrong 是独立错题表，不复用托福错题本。
题型字段：task_type ∈ {text_completion, sentence_equivalence, reading, quant_compare, quant_problem, awa_issue, awa_argument}； limit_second 按 90 秒/题（Verbal）、105 秒/题（Quant）、1800 秒/篇写作（封顶 3600）折算，下限 300 秒。
④ GRE 全真套题 gre_suite_*
一键组卷时把分块题目整篇复制进 gre_suite_section / gre_suite_question，因此套题与题库解耦。
读图要点：① 全库只有 2 处物理外键（tpo 链），所以删改题库不会级联删掉套题与作答记录。② 套题子表是同一道题的第二份拷贝（full_question / gre_suite_question），改题库不影响已生成的卷。③ 结果页顺序依赖 sort_index 而非 id，复制题目时必须原样写入。
